اتصال سریع و امن فروشگاه ووکامرس به اپلیکیشن موبایل نوین سایت با اسکن کد QR و ارائه وب‌سرویس‌های تجمیعی داشبورد و اعلان‌ها.

== Description ==
افزونه اختصاصی «مدیریت فروشگاه نوین سایت» جهت اتصال پایدار و فوق سریع اپلیکیشن اندروید به سایت‌های وردپرسی طراحی شده است.
طراحی و توسعه: تیم نوین سایت (https://novinsite.com)

ویژگی‌ها:
1. ایجاد منوی اختصاصی «📱 فروشگاه نوین سایت» در پیشخوان وردپرس
2. تولید کد QR با یک کلیک برای جفت‌سازی و ورود سریع به اپلیکیشن بدون نیاز به تایپ دستی کلیدها
3. اندپوینت پرسرعت تجمیع آمار داشبورد جهت کاهش ترافیک سرور و افزایش چشمگیر سرعت اپلیکیشن موبایل
4. لاگ خودکار رویداد سفارشات برای اعلان‌های لحظه‌ای در اپلیکیشن

== Installation ==
1. پوشه `woo-mobile-connector` را در مسیر `wp-content/plugins/` آپلود کنید (یا آن را به صورت فایل zip فشرده کرده و از بخش افزونه‌ها > افزودن > بارگذاری افزونه نصب نمایید).
2. افزونه را در پنل وردپرس فعال کنید.
3. به منوی جدید «📱 فروشگاه نوین سایت» مراجعه کنید.
4. اپلیکیشن موبایل را باز کرده و با دوربین گوشی کد QR نمایش داده شده را اسکن کنید.
