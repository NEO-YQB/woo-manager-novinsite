# NovinSite Store Manager - Production Releases

This folder contains pre-built distribution assets and release packages.

---

## 🔌 WordPress Companion Plugin
- **File**: [`woo-mobile-connector.zip`](woo-mobile-connector.zip)
- **Installation**:
  1. Go to your WordPress Admin dashboard.
  2. Navigate to **Plugins > Add New > Upload Plugin**.
  3. Select `woo-mobile-connector.zip` and click **Install Now**.
  4. Click **Activate Plugin**.
  5. Go to **📱 NovinSite Store** menu to display the instant pairing QR Code.

---

## 📱 Android Application (APK)
- **File**: `app-release.apk` (Generated locally or downloaded from GitHub Releases)
- **Local Build**:
  - Run `build_release.bat` (Windows cmd) or `./build_release.ps1` (PowerShell) to compile the latest release APK.
- **GitHub Actions**:
  - Download the latest signed APK directly from the **Releases** or **Actions** tab on the GitHub repository.
